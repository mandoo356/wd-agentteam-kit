# slack-server — 슬랙 연결 (모듈 4)

프로그램은 **이미 들어 있습니다.** 모듈 4에서 여러분이 할 일은 `.env` 에 열쇠 2개를 넣는 것뿐입니다.

| 파일 | 뭐 하는 파일인가 | 고쳐도 되나 |
|---|---|---|
| `server.py` | 슬랙과 직원을 잇는 본체 | ⚙️ 엔진 — 안 고쳐도 됩니다 |
| `claude_bridge.py` | Claude 를 부르는 부분 | ⚙️ 엔진 |
| `personas.py` | **슬랙에 뜨는 이름·아이콘·인사말** | 🎨 마음껏 고치세요 |
| `agent_channels.py` | **어느 채널이 어느 직원인지** | 🎨 마음껏 고치세요 |
| `.env` | 슬랙 열쇠 | 🔒 여러분이 만듭니다 |

## 이 프로그램이 하는 일

슬랙에 말을 걸면 → 이 프로그램이 받아서 → 여러분의 직원(에이전트)을 깨우고 → 답을 슬랙에 올립니다.
**이게 꺼져 있으면 슬랙에 말을 걸어도 아무도 대답하지 않습니다.**

## 🔒 `.env` 는 비밀번호와 같습니다

슬랙 열쇠(토큰)가 들어가는 파일입니다.

- 절대 남에게 주지 마세요. 폴더를 통째로 공유할 때도 `.env` 는 빼고 주세요.
- 인터넷에 올리지 마세요. 깃허브에 올리면 몇 분 만에 털립니다.
- 화면 공유 중에 이 파일을 열지 마세요.

`점검.py` 는 이 파일의 **내용을 읽지 않습니다.** 항목 이름이 있는지만 봅니다.

## 직원 부르는 법 (2026-09-08 판)

- 이름 없이 말하면 **팀장(staff1)** 이 받고, 남의 일이면 그 직원 이름으로 답합니다 (줄마다 `이름: 말` → 그 직원 말풍선).
- 문장 맨 앞에 이름을 붙이면 그 직원이 직접 받습니다: `교재대리 불러서 …` / `@교재대리 …` / `#교재대리` 채널.
- `팀 소개` 5명 인사 · `새 대화` 어제 대화와 잘못 기억한 이름을 지움. 대화가 30번을 넘으면 서버가 스스로 새 대화를 시작합니다.
- 답이 느리면 `.env` 의 `AGENT_MODEL=sonnet`(기본) 인지 확인. 팀 규약·inbox 는 서버가 미리 읽어 넣으므로 직원이 파일을 읽으러 가지 않습니다.
- 서버는 켤 때 `workspace/memory/facts.md` 의 `이름:` 을 읽어 **대표 이름**을 알고 시작합니다 (`.env` 에 `OWNER_NAME=` 을 적으면 그게 우선).
- `personas.py` 의 아이콘은 `📄` 그대로 넣어도 됩니다. 인사말의 `[무엇]` 은 꼭 채우세요 (카드 P11).

## 켜는 법 (모듈 4에서 같이 합니다)

```

```

검은 창에 `Bolt app is running!` 이 뜨면 성공입니다. **그 창은 닫으면 안 됩니다.**
