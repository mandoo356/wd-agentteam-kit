# 강사 프로필 덱 스킬 설치 안내

강사 개인 브랜딩 프로필을 **HTML 슬라이드(1920×1080)** 로 만드는 스킬입니다.
표지→강사소개→강의이력→언론보도→WHY→교육후기→교육현장→감사, 8종 슬라이드 구조를 내장하고
있고, 색은 여러분이 P1에서 만든 `facts.md` 값을 그대로 씁니다.

## 1. 설치

폴더를 통째로 **스타터킷 안** `.claude/skills/` 에 `프로필` 이라는 이름으로 복사합니다.
(홈 폴더의 `.claude` 가 아닙니다 — 카드 P4 와 같은 규칙이고, 검사 스크립트 경로도 여기에 맞춰져 있습니다.)

```
xcopy /E /I "프로필-스킬" ".claude\skills\프로필"
```

Claude Code를 재시작하면 "강사 프로필 만들어줘" 같은 말에 자동으로 이 스킬이 켜집니다.

## 2. 사전 조건

| 필요한 것 | 확인 방법 | 없으면 |
|---|---|---|
| `workspace/memory/facts.md` | P1에서 이미 만들었어야 함 | P1 카드부터 다시 |
| playwright 패키지 | `py -3 -c "import playwright"` | `pip install playwright` |
| 시스템 Chrome | Chrome이 설치돼 있는가 | google.com/chrome |

QA 스크립트(`qa_screenshot.py`)는 **시스템 Chrome을 그대로 씁니다** — 다른 스킬(네이버·구글 플로우)과
마찬가지로 별도 브라우저를 추가로 받지 않습니다.

## 3. 쓰는 법

```
내 강사 프로필 덱 만들어줘.

강의 경력: (내 소속·직함)
자격: (내 자격증)
기업 교육 레퍼런스: ...
캐치프레이즈: ...
이 강사를 선택해야 하는 이유 3가지: ...
연락처: 이메일, 휴대폰
```

빠진 항목이 있으면 직원이 **한 번에 모아서** 물어봅니다. 사진·언론보도·후기는 없으면 그
슬라이드를 빼고 진행합니다.

## 4. QA 게이트 — 완성 전 반드시 통과

스킬이 알아서 돌리지만, 걸린 게 있으면 이렇게 직접 확인할 수 있습니다.

```
py -3 .claude/skills/프로필/scripts/validate.py workspace/결과물/파일명.html
py -3 .claude/skills/프로필/scripts/qa_screenshot.py workspace/결과물/파일명.html
```

`validate.py`는 슬라이드 순서·규격·색상(자기 `facts.md` 색인지)·잔존 자리표시자를 자동으로 봅니다.
`qa_screenshot.py`는 슬라이드를 전부 캡처해 `workspace/결과물/qa_profile/` 에 저장합니다 —
글자가 슬라이드 밖으로 넘쳤는지(overflow)는 사람 눈으로 마지막에 확인하세요.

## 절대 금지 (스킬 안에도 명시돼 있음)

- 경력·자격·고객사·수치를 지어내지 않는다.
- 서양인 스톡 사진을 쓰지 않는다.
- `facts.md`에 없는 임의 색상을 새로 만들지 않는다.
- 외부 폰트·이미지를 인터넷에서 불러오지 않는다 (강의장 와이파이 없이도 열려야 함).
