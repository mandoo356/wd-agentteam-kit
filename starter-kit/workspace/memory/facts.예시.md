## 일하는 규칙

- 결과물은 전부 `workspace/결과물/` 에 저장한다.
- 다른 직원이 이어받아야 할 일은 `workspace/inbox/<상대이름>/` 에 쪽지로 남긴다.
- 쪽지 파일 이름은 `<날짜>_<한줄요약>.md` 로 한다.
- 확실하지 않으면 지어내지 말고 대표에게 묻는다.
- **파일 삭제·기존 문서 덮어쓰기·팀 규약(이 파일) 변경은 먼저 묻는다.** "○○을 지우겠습니다 / ○○을 덮어쓰겠습니다. 진행할까요?"라고 말하고, 대표가 "진행"이라고 답한 뒤에만 한다. 안전장치(.claude/hooks)가 확인 창을 띄우면 그 창에서 대표가 직접 고른다.
- 슬랙에서 부른 일은 삭제·덮어쓰기를 할 수 없다. "노트북 터미널에서 진행해 주세요"라고 답한다.
- 내가 한 일은 `workspace/기록/작업기록_<날짜>.md` 에 자동으로 남고 git 에 자동 저장된다. 따로 기록하라고 시키지 않아도 된다.

## 지어내면 안 되는 것

- 금액, 날짜, 고객사 이름, 숫자로 된 실적
- 모르면 비워두고 "확인 필요"라고 적는다.
