# 내가 고친 것 — 이유까지

대표가 결과물을 고칠 때마다 **왜 고쳤는지**가 한 줄씩 쌓입니다.
같은 지적이 **2번** 되면 직원이 먼저 "규칙으로 만들까요?" 라고 묻습니다.

| 날짜 | 무슨 일 | 내가 뭘 고쳤나 | 왜 (내 말 그대로) | 반복 |
|---|---|---|---|---|

- 「왜」 칸이 비면 규칙으로 올릴 수 없습니다. 고쳐달라고 할 때 **한마디만** 덧붙여 주세요.
  예 — "이 고객사는 보수적이라 그래", "그 담당자가 숫자를 먼저 봐"
- 규칙이 된 줄은 끝에 `규칙됨 (날짜)` 가 붙습니다.
- 이 표를 손으로 채우지 않아도 됩니다. 직원이 일을 마칠 때마다 적습니다.
