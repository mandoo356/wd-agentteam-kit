# 나의 AI 회사 만들기 — 스타터킷

이 폴더가 여러분의 회사가 될 자리입니다. 지금은 뼈대만 있고, 오늘 하루 동안 내용을 채웁니다.

---

## 가장 쉬운 길 — 명령어 한 줄 설치

시작 메뉴에서 **PowerShell** 을 열고(관리자 권한 필요 없음) 아래 한 줄을 붙여넣고 Enter.
붙여넣기는 **마우스 오른쪽 클릭**입니다.

```powershell
irm https://raw.githubusercontent.com/mandoo356/wd-agentteam-kit/main/install.ps1 | iex
```

이 한 줄이 스타터킷을 받아 `C:\에이전트\01_KIT\starter-kit` 에 설치하고, 환경점검까지 이어서 돌립니다.
같이 만들어지는 **`C:\에이전트\내자료\`** 에 제안서 3개·블로그 글 3개·회사 로고를 수업 전에 넣어 두세요 (아래).
프로그램(Node·Git·Claude Code…)도 설치 파일을 받는 게 아니라 **명령어로** 깔립니다. Y 만 누르면 됩니다.
인터넷이 켜져 있어야 합니다. 이미 설치돼 있으면 덮어쓰지 않습니다.

---

## 예비: ZIP으로 받았다면 — 폴더부터 자동으로 만들기

1. ZIP 파일에서 **모두 압축 풀기**를 먼저 합니다.
2. 풀린 스타터킷의 **`00_폴더생성_및_설치.bat`**을 더블클릭합니다.
3. 프로그램이 아래 표준 위치를 만들고 가벼운 스타터킷을 복사합니다.

```text
C:\에이전트\01_KIT\starter-kit
```

이동을 오래 걸리게 하는 `office/node_modules`와 캐시·로그·비밀키는 복사하지 않습니다.
기존 설치가 있으면 덮어쓰지 않으며, 설치 후 탐색기와 환경점검을 이어서 열어줍니다.

## 설치된 폴더에서 시작 전에 딱 하나만

이 폴더의 **`환경점검.bat` 을 더블클릭**하세요. 검은 창이 열리고 알아서 돕니다.

- 프로그램(Node·Python·Git·Claude Code…)이 깔렸는지, 버전이 맞는지 봅니다
- 빠진 게 있으면 **자동 설치할지 물어보고** 깔아줍니다 (Y 만 누르면 됩니다)
- 로그인이 필요한 것(Claude Code·슬랙 열쇠)은 **그 화면을 바로 띄워** 줍니다 — 로그인은 본인이 직접
- 끝나면 체크리스트가 검은 창과 브라우저(`환경점검_결과.html`)에 뜹니다

✅ 가 필수 항목에 전부 켜지면 준비 끝입니다. ❌ 가 있으면 그 줄에 뭘 해야 하는지 적혀 있어요.
슬랙 열쇠는 **모듈 4 전까지**만 준비되면 되니 당장 없어도 괜찮습니다.

> 파이썬이 없어도 돌아가게 PowerShell 로 만들어져 있습니다.
> "Windows 의 PC 보호" 창이 뜨면 「추가 정보 → 실행」. 인터넷이 켜져 있어야 합니다.

옛 방식(파이썬이 이미 있을 때)도 그대로 됩니다 — 폴더 안 빈 공간에서
**Shift + 오른쪽 클릭 → "여기에 PowerShell 창 열기"** 후:

```
py -3 점검.py 0
```

> 붙여넣기는 **마우스 오른쪽 클릭**입니다. Ctrl+V 는 안 될 때가 있어요.

## 내 자료 미리 넣기 — `C:\에이전트\내자료\`

설치가 이 폴더를 만들어 둡니다. 모듈 3.5(내 자료)에서 직원이 **내 문체·구성**을 여기서 배웁니다.
**수업 전날까지** 넣어 두면 당일이 편합니다. 없는 칸은 비워 두어도 수업은 진행됩니다.

| 폴더 | 넣을 것 | 개수 |
|---|---|---|
| `내자료\제안서\` | 내가 실제로 보낸 제안서 (pptx·pdf·docx·hwp) | **3개** |
| `내자료\블로그\` | 내가 쓴 블로그 글 (txt·docx·pdf, 또는 글 주소를 적은 txt) | **3개** |
| `내자료\로고\` | 회사 로고 (png·jpg·svg). 명함·홈페이지 캡처도 됩니다 | **1개** |
| `내자료\프로필\` | (선택) 강사 프로필·이력서 | 3개 |

폴더 안의 `여기에_넣으세요.txt` 에 같은 내용이 적혀 있습니다. 환경점검 「선택」 항목에 몇 개 들어갔는지 표시됩니다.

## 폴더가 뭐가 뭔지

| 폴더 | 여기에 뭐가 들어가나 | 내가 할 일 |
|---|---|---|
| `.claude/agents/` | 직원들. 한 명당 파일 하나 | **모듈 1에서 만듭니다** |
| `.claude/skills/` | 일하는 방법 설명서 | **모듈 2에서 만듭니다** |
| `workspace/inbox/` | 직원끼리 넘기는 쪽지함 | 모듈 3에서 채워집니다 |
| `workspace/memory/` | 팀 전체가 아는 규약 | **모듈 3에서 씁니다** |
| `workspace/결과물/` | 실제로 만들어진 것들 | 모듈 2부터 저절로 쌓입니다 |
| `slack-server/` | 슬랙에서 부르면 깨워주는 프로그램 | 프로그램은 이미 들어 있습니다. **모듈 4에서 `.env` 에 열쇠만** |
| `office/` | 가상 오피스 화면 | 프로그램은 이미 들어 있습니다. **모듈 5에서 `company.config.ts` 만** |
| `flow-image-JJ/` | 구글 플로우로 이미지 대량 생성하는 스킬 | 모듈 3.5에서 `.claude/skills/` 로 복사 + 최초 1회 로그인 |
| `naver-blog/` | 네이버 블로그 임시저장 자동화 | 프로그램은 이미 들어 있습니다. **모듈 3.5에서 `--blog-id` 만** |
| `프로필-스킬/` | 강사 프로필 덱(HTML 슬라이드) 완성 스킬 | `.claude/skills/프로필` 로 복사 (전문 스킬 S7) |

> `slack-server` 와 `office` 는 **완성된 프로그램이 이미 들어 있습니다.**
> 여러분이 만드는 건 직원(`.claude/agents/`)과 스킬(`.claude/skills/`)이고,
> 저 둘은 그걸 **불러 쓰고 보여주는** 도구입니다. 설정 한 줄씩만 채우면 됩니다.

## 카드가 세 벌 있습니다

| 카드 | 언제 | 몇 장 |
|---|---|---|
| `프롬프트카드.md` | **오늘 강의장에서** — 모듈 0~6 순서대로 | 기본 P0~P14 + 연결·확장 P15~P23 + 관문 4개 |
| `프롬프트카드_연결.md` | 모듈 4 통과 후. 시간 남으면 강의장, 아니면 집 | 4장 (C1~C4) |
| `프롬프트카드_전문스킬.md` | 집에 가서, 내가 자주 하는 일부터 | 5장 (블로그·교안·메일·프로필·카드뉴스) |

**`프롬프트카드_연결.md` 를 빠뜨리지 마세요.** 모듈 6까지 하면 직원이 슬랙에서 대답은 하는데
**내 일정도 내 자료도 모릅니다.** 그 상태로 집에 가면 "만들긴 했는데 안 쓰게 되는" 자리에서 멈춥니다.
캘린더를 붙이고(C1) 내 제안서 폴더를 열어주면(C2~C4) 그때부터 실제로 씁니다.

## 합격 판정 받는 법

모듈이 끝날 때마다 검은 창에서:

```
py 점검.py 1     ← 모듈 1이 끝났으면
py 점검.py 2     ← 모듈 2가 끝났으면
```

✅ 가 전부 켜지면 다음으로 넘어갑니다. ❌ 가 있으면 **그 줄만** 고치면 돼요.
`py` 가 안 먹으면 `py -3 점검.py 1` 로 해보세요.

**`점검.py` 는 고치지 마세요.** 여러분이 만든 게 규격에 맞는지 보는 채점표입니다.

## 끝나고 내 회사 가져가기

스타터킷 폴더의 **`02_내작업_백업.bat`**을 더블클릭하세요.

- 내가 만든 `workspace`, 직원, 스킬, 오피스 회사 설정만 ZIP으로 묶습니다.
- `.env`, 슬랙 열쇠, 로그인 상태, `node_modules`는 넣지 않습니다.
- 자동 설치한 경우 `C:\에이전트\04_LEARNER_BACKUP`에 저장됩니다.
- 만들어진 ZIP을 개인 USB나 클라우드에 보관하세요.

새 PC에서 복원할 때는 깨끗한 스타터킷을 먼저 설치하고 슬랙 서버와 오피스를 끈 뒤,
백업 ZIP의 `workspace`, `.claude`, `office`를 설치된 스타터킷에 덮어씁니다.
슬랙 `.env`와 구글·네이버 로그인은 보안상 백업되지 않으므로 새 PC에서 다시 설정합니다.

## 이름 끝에 `.txt` 가 붙은 파일

`_예시_직원.md.txt` 처럼 `.txt` 로 끝나는 건 **보라고 넣어둔 견본**입니다.
채점에는 안 들어가니 열어보고 참고만 하세요. 여러분이 만드는 진짜 파일은 `.txt` 없이 만듭니다.
