# 메일 연동 (mail)

직원(Claude Code)이 **내 메일함을 읽고, 강의 문의를 골라내고, 답장 초안을 쓰는** 모듈입니다.
네이버 · 다음 · 지메일을 지원합니다. 실제로 보내는 건 내가 "보내"라고 할 때만입니다.

## 무엇을 하나

| 파일 | 하는 일 |
|---|---|
| `mail_check.py` | 로그인만 해 봅니다. `OK: naver hong@naver.com IMAP ✅ SMTP ✅` 한 줄이 나오면 연동 끝 |
| `mail_read.py` | 받은편지함 최근 N통을 보여줍니다. 강의 문의로 보이는 메일엔 📌문의 표시. 읽음 표시는 안 바뀝니다 |
| `mail_send.py` | 메일을 보냅니다. 단, `--approved` 가 없으면 **초안만 보여주고 안 보냅니다** |
| `skill/SKILL.md` | 직원이 언제 어느 스크립트를 쓰는지 적힌 안내서. `.claude/skills/mail/SKILL.md` 로 복사하면 직원이 읽습니다 |
| `.env.example` | 설정 견본. 복사해서 `.env` 로 만듭니다 |

직접 실행할 일은 거의 없습니다. 슬랙에서 "새 메일 있어?" 라고 하면 직원이 알아서 돌립니다.

## 준비 — 앱 비밀번호 받기

평소 로그인 비밀번호로는 안 됩니다. 프로그램용으로 따로 발급하는 **앱 비밀번호**가 필요합니다.

**네이버**
1. 네이버 메일 → 오른쪽 위 **환경설정** → **POP3/IMAP 설정** → IMAP/SMTP 설정 **"사용함"** 저장
2. 네이버 계정(nid.naver.com) → **보안** → **2단계 인증** 켜기
3. 같은 화면 **애플리케이션 비밀번호** → 이름 아무거나(예: 에이전트) → 발급된 값 복사

**다음(카카오메일 포함)**
1. Daum 메일 → **설정** → **IMAP/SMTP 사용** 켜기
2. 카카오계정 → **보안** → **2단계 인증** 켜기
3. 같은 화면 **앱 비밀번호** 발급 → 값 복사

**지메일**
1. 구글 계정(myaccount.google.com) → **보안** → **2단계 인증** 켜기
2. 검색창에 "앱 비밀번호" → 앱 이름 입력 → 발급된 16자 복사 (띄어쓰기는 지워도 되고 그대로 붙여도 됩니다)

## `.env` 만들기

1. `mail/.env.example` 을 복사해서 이름을 `.env` 로 바꿉니다. (확장자 `.txt` 가 붙지 않게 — VS Code 로 저장하면 안전합니다)
2. 네 줄을 채웁니다.
   ```
   MAIL_PROVIDER=naver              ← naver / daum / gmail
   MAIL_USER=hong@naver.com         ← 내 메일 주소 전체
   MAIL_APP_PASSWORD=발급받은값       ← 앱 비밀번호 (따옴표·공백 없이)
   MAIL_ALLOW_EXTERNAL=0            ← 그대로 0
   ```
3. 🔒 `.env` 는 비밀번호입니다. 남에게 주거나 인터넷·깃허브에 올리지 마세요. (`.gitignore` 에 이미 들어 있습니다)

`slack-server/.env` 에 같은 네 줄을 넣어도 됩니다. `mail/.env` 가 있으면 그쪽이 먼저입니다.

## 점검

스타터킷 폴더에서:
```
py -3.14 mail\mail_check.py
```
- `OK: naver hong@naver.com IMAP ✅ SMTP ✅` → 끝. 슬랙에서 "새 메일 있어?" 해 보세요.
- `FAIL: … ❌ 원인 → 해결` → 아래 "자주 나는 오류" 를 보세요.

## 자주 나는 오류 3개

**1. `IMAP 사용이 꺼져 있는 것 같습니다`**
메일 설정에서 IMAP 을 안 켠 겁니다. 네이버는 메일 → 환경설정 → POP3/IMAP 설정에서 "사용함", 다음은 설정 → IMAP/SMTP 사용. 저장한 뒤 1~2분 기다렸다가 다시 점검하세요.

**2. `로그인 실패 — 앱 비밀번호가 틀렸거나 평소 로그인 비밀번호를 넣은 것 같습니다`**
가장 흔합니다. 평소 로그인 비밀번호는 **안 됩니다**. 위 "앱 비밀번호 받기"대로 새로 발급받아 `MAIL_APP_PASSWORD=` 뒤에 붙여넣으세요. 앞뒤 공백·따옴표가 없는지, `MAIL_USER` 가 전체 주소(`@` 포함)인지도 확인하세요.

**3. 앱 비밀번호 메뉴가 안 보인다**
**2단계 인증을 먼저 켜야** 앱 비밀번호 메뉴가 생깁니다. 네이버 계정·카카오계정·구글 계정 모두 같습니다. 2단계 인증을 켠 뒤 다시 들어가 보세요.

그 밖에 `연결하지 못했습니다` 가 나오면 인터넷·회사 방화벽·VPN 문제입니다. 다른 와이파이(휴대폰 핫스팟)로 한 번 해 보세요.

## 안전 규칙

- **초안까지만.** 직원은 답장 초안을 `workspace/결과물/` 에 저장하고 화면에 보여줄 뿐, 보내지 않습니다. 내가 "보내"라고 말한 그 건만 `--approved` 로 나갑니다.
- **외부 발송 잠금.** `MAIL_ALLOW_EXTERNAL=0` 이면 내 주소로만 보낼 수 있습니다. 고객사 등 남에게 보내려면 내가 직접 `1` 로 바꿔야 합니다. 직원은 이 값을 건드리지 않습니다.
- **비밀번호는 어디에도 찍히지 않습니다.** 화면·로그·오류 메시지 모두. 직원이 비밀번호를 묻는다면 그건 잘못된 동작이니 답하지 마세요.
- **읽음 표시를 바꾸지 않습니다.** 직원이 읽어도 메일함에는 "안 읽음" 그대로 남습니다.
