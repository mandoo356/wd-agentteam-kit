# 직원 견본 — 프리랜서 강사 기본 세트 8명

강의하는 사람이 **반복해서 하는 일 8가지**를 직원 8명으로 미리 만들어 둔 것입니다.
모듈 1 카드 **P3** 에서 이 폴더의 파일을 `.claude/agents/` 로 데려갑니다.
여기 있는 파일은 **견본**이라 직원으로 동작하지 않습니다 (직원은 `.claude/agents/` 에 있는 것만).

| 키 | 이름 | 담당 | 이렇게 부르면 나옵니다 |
|---|---|---|---|
| staff1 | 팀장 | 제안서·견적·문의 접수·회신 초안. 이름 없이 부르면 받는 사람 | "제안서 써줘", "문의 왔어" |
| staff2 | 교안수석 | 강의 설계 — 모듈·시간표·활동·스크립트 | "교안 짜줘", "커리큘럼 설계" |
| staff3 | 교재대리 | 교재·워크북·핸드아웃·평가지 (인쇄물) | "워크북 만들어줘", "핸드아웃" |
| staff4 | 블로그대리 | 강의 후기·현장 스케치·과정 소개 글 | "블로그 써줘", "강의 후기" |
| staff5 | 정산과장 | 강사료 장부·입금 확인·미수금·세금 일정 | "입금 확인", "이번 달 수입" |
| staff6 | 프로필대리 | 강사 프로필 — 기업용 · 공공기관용 · 강의 주제 맞춤 세 갈래 | "기업 프로필", "공공기관 프로필", "리더십 프로필" |
| staff7 | 일정매니저 | 캘린더 등록·조회·조정, 이동·마감 리마인더 | "일정 잡아줘", "언제 비어?" |
| staff8 | 디자이너 | 인스타 카드뉴스·SNS 이미지·배너 시안, 캡션·해시태그 | "카드뉴스 만들어줘", "인스타 올릴 거" |

이름·아이콘은 모듈 4 카드 **P11** 의 예시 표와 같습니다. 그대로 두면 P11 도 한 번에 지나갑니다.

## 파일마다 들어 있는 것

- `---` 머리: `name`(staff1~8 — **바꾸지 마세요**, 파일 이름·슬랙 연결과 짝) · `description`(언제 부르나) · `tools`
- 언제 부르나 / 내가 하는 일 / 시작할 때 묻는 것 / 일하는 방식 / 지어내지 않는 것 / 혼잣말
- 모듈 3 의 팀 규칙(결과물은 `workspace/결과물/`, 넘길 때는 `workspace/inbox/<staff번호>/`, 시작 전 `facts.md` 읽기)이 **이미 들어 있습니다.** P6·P7 을 붙여넣으면 "이미 있음"이라고 답하는 게 정상입니다.

## 내 일에 맞게 고치기

- 담당을 바꾸고 싶으면 클로드에게 말로: `staff4 를 블로그 대신 유튜브 기획 담당으로 바꿔줘. 파일 형식은 그대로.`
- 강사가 아니면(디자이너·개발자·쇼핑몰…) 이 견본 대신 카드 **P3-직접** 으로 내 일 8가지를 새로 만듭니다.
- 견본을 다시 가져오고 싶으면 이 폴더에서 다시 복사하면 됩니다. 이 폴더는 지우지 마세요.
