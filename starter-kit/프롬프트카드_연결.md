# 연결 카드 4장 — 내가 이미 가진 것을 직원에게 물려주기

> 📌 **언제 하나**: 모듈 4(슬랙)를 통과한 뒤. 강의장에서 시간이 남으면 거기서, 아니면 집에서.
> 한 장에 10~15분. **C1(캘린더)과 C2(폴더)는 순서를 지켜야** 하고, C3·C4는 필요할 때만.

여기까지 오면 직원 8명이 슬랙에서 대답합니다. 그런데 아직 **아무것도 모릅니다.**
내 일정도 모르고, 내가 3년 동안 쌓은 제안서도 못 봅니다. 그래서 매번 처음부터 설명해야 합니다.

이 네 장은 **이미 내 컴퓨터·구글 계정에 있는 것을 직원에게 물려주는** 카드입니다.

| 카드 | 하는 일 | 다 하면 |
|---|---|---|
| **C1** | 구글 캘린더 연결 | "다음 주 화요일 비어?" 가 됩니다 |
| **C2** | 내 자료 폴더 열어주기 | "작년 제안서 참고해서" 가 됩니다 |
| **C3** | 그 폴더의 PPT·PDF 읽히기 | 파일 **내용**까지 봅니다 |
| **C4** | 내 자료로 스킬 만들기 | 내 문체·구성이 기본값이 됩니다 |

---

## C1 — 구글 캘린더 연결하기

> 📌 **담당은 staff8(귀요미매니저)입니다.** 스킬 폴더가 아니라 claude.ai 커넥터로 붙는
> 연동이라 `.claude/skills/`에는 아무것도 안 생깁니다 — 이 카드가 곧 staff8의 "스킬"입니다.

### 붙이기

Claude Code 를 켜둔 채로 **브라우저**에서 연결합니다.

```
claude.ai  →  설정  →  커넥터(Connectors)  →  Google Calendar  →  연결
```

구글 로그인 창이 뜨면 **강의 일정이 들어 있는 계정**으로 승인하세요.
계정이 여러 개면 여기서 자주 틀립니다.

### 관문 — "연결됨" 을 믿지 말고 **시켜서** 확인하세요

**이 카드에서 제일 중요한 줄입니다.** 커넥터 화면은 초록색 `연결됨` 인데
정작 직원은 캘린더를 못 보는 일이 흔합니다. 증상이 "캘린더가 안 돼요" 하나뿐이라
설정을 아무리 다시 봐도 원인이 안 보입니다.

```
구글 캘린더에서 오늘부터 7일간 일정을 조회해서 건수와 제목만 알려줘.
조회만 하고 등록·수정은 하지 마.

읽지 못하면 "왜 못 읽었는지"를 한 줄로 적어줘. 추측하지 말고 실제로 시도한 결과만.
```

**통과 기준** — 실제 일정 제목이 나오면 통과. 건수가 `0건` 이어도 **조회 자체가 됐으면 통과**입니다.

### ❌ "연결됨인데 못 읽어요" — 원인은 둘 중 하나입니다

| 원인 | 어떻게 아나 | 해결 |
|---|---|---|
| **켜둔 채로 연결했다** | 방금 연결했다면 십중팔구 이것 | **Claude Code 를 완전히 끄고 다시 켠다** |
| **장기 토큰을 쓰고 있다** | `CLAUDE_CODE_OAUTH_TOKEN` 을 환경변수에 넣어둔 적이 있다 | 그 변수를 빼고 다시 켠다 |

> ⚠️ **첫 번째가 압도적으로 많습니다.** 프로그램은 켜질 때 "내가 쓸 수 있는 도구 목록"을
> 한 번 적어두고 그걸 계속 씁니다. 나중에 커넥터를 붙여도 **이미 켜져 있던 창은 모릅니다.**
> 설정을 고치는 게 아니라 **껐다 켜는 것**이 유일한 해결입니다.
>
> ⚠️ 두 번째는 드물지만 한번 걸리면 오래 헤맵니다. 그 토큰으로 로그인하면
> **캘린더·지메일·드라이브가 통째로** 안 붙습니다. 토큰은 "프로그램용 열쇠"라
> 계정에 매달린 커넥터를 데려오지 못하기 때문입니다.

### 쓰기

```
9월 3일 오후 2시에 [강의] 삼성전자 리더십 3시간 일정을 넣어줘.
색은 기본색으로 하고, 앞뒤로 이동시간 1시간씩도 같이 잡아줘.
```

> 💡 **색 규칙을 팀 규약(`facts.md`)에 적어두세요.** 강의는 기본색, 마감은 보라,
> 입금은 초록 — 이렇게 정해두면 매번 말하지 않아도 그대로 넣습니다.
> 안 정해두면 직원이 매번 다른 색을 골라서 달력이 지저분해집니다.

## C2 — 내 자료 폴더 열어주기

직원은 **작업 폴더 밖을 모릅니다.** 내 제안서가 드롭박스에 있어도 못 봅니다.
열어줄 폴더를 **경로째** 알려주세요. 설치 때 만들어진 `C:\Agent\MyData\` 가 기본 창고입니다 —
드롭박스 등 다른 폴더를 더 열어주고 싶으면 아래에 줄을 추가하세요.

```
아래 폴더들을 앞으로 참고할 자료 창고로 삼아줘.

- 제안서: C:/Agent/MyData/Proposal
- 블로그: C:/Agent/MyData/Blog
- 로고: C:/Agent/MyData/Logo

각 폴더에 뭐가 몇 개 있는지 종류별로 세어서 표로 보여줘.
그리고 이 경로를 팀 규약(facts.md)에 "자료 창고" 항목으로 적어줘.
원본은 절대 고치거나 지우지 말고 읽기만 한다는 규칙도 같이 적어줘.
```

**통과 기준** — 파일 개수가 종류별로(pptx 몇 개, pdf 몇 개…) 나오면 통과.

### ⚠️ 여기서 진짜 자주 나는 사고 두 가지

**1. 폴더 이름을 두루뭉술하게 부르면 못 찾습니다.**
"GPT 제안서 폴더 봐줘" 라고 했더니 후보를 **4개** 찾아놓고 멈춘 일이 실제로 있었습니다
(`챗GPT제안서`, `챗 지피티제안서`, `예전GPT/GPT 자료`, `01.최근gpt`).
**경로를 통째로** 주는 게 가장 빠릅니다. 탐색기 주소창에서 복사하면 됩니다.

**2. 원본을 고치지 말라고 반드시 못 박으세요.**
자료 창고는 **진실의 원본**입니다. 직원이 정리한답시고 이름을 바꾸거나 옮기면
드롭박스가 그걸 그대로 동기화해서 다른 기기에서도 사라집니다.
위 프롬프트의 마지막 줄이 그 방지선입니다. **지우지 마세요.**

## C3 — 그 폴더의 PPT·PDF 를 읽히기

### 왜 필요한가 — 폴더만 열어주면 **파일 이름까지만** 봅니다

C2 까지 하면 목록은 봅니다. 그런데 정작 제안서 **안에 뭐가 적혀 있는지는 못 읽습니다.**
실제로 이렇게 답합니다:

> "pptx 는 바이너리라 못 엽니다 — 파일명만 확인했습니다"

PPT·PDF 는 **글자 파일이 아니라 압축된 덩어리**라 그냥은 안 열립니다. 도구를 하나 쥐어줘야 합니다.

```
PPTX·PDF·DOCX 파일에서 글자만 뽑아내는 파이썬 도구를 만들어줘.

- 파일 하나든 폴더 하나든 받을 수 있게 해줘. 폴더면 안쪽까지 전부 훑어줘
- PPT 는 슬라이드 번호와 **표 안의 글자까지** 뽑아줘 (커리큘럼·견적표가 다 표 안에 있어)
- 파일당 출력 길이를 조절할 수 있게 해줘
- 한글(.hwp)은 못 읽으면 "못 읽음"이라고만 표시하고 넘어가줘
- 필요한 라이브러리가 없으면 먼저 설치해줘

만든 다음, C2 에서 정한 제안서 폴더로 실제로 한 번 돌려서 결과를 보여줘.
```

**통과 기준** — 내 제안서의 **커리큘럼 표 내용**이 화면에 그대로 나오면 통과.

> ⚠️ **도구는 "파일"로 만들어야 합니다.** 스킬 문서에 코드를 글로만 적어두면
> 아무도 안 씁니다 — 쓸 때마다 옮겨 적어야 하니까요. 실제로 그렇게 방치된 적이 있습니다.
> **실행되는 파일**로 만들고, 스킬에는 "이 명령을 실행하라" 한 줄만 적으세요.

## C4 — 내 자료로 스킬 만들기

이제 직원이 내 제안서를 **읽을 수 있습니다.** 마지막으로, 그걸 **기준선**으로 삼게 합니다.
모듈 2의 P4 에서 만든 제안서 스킬을 **내 실물 자료로 덮어쓰는** 것입니다.

```
C2 에서 정한 제안서 폴더를 C3 의 도구로 전부 훑어줘.
그 다음 아래를 정리해서 제안서 스킬(SKILL.md)을 고쳐줘.

1. 내가 실제로 쓰는 모듈 구성 (M1/M2/M3… 몇 개로 나누는지, 한 모듈이 몇 분인지)
2. 자주 등장하는 표현·제목 어투 — 지어내지 말고 **실제 문장 3개**를 근거로 들어줘
3. 슬라이드 순서 (표지 → 기대효과 → 커리큘럼 → …)
4. 시간대별 구성이 몇 시간짜리로 나뉘어 있는지 (3H·4H·8H 등)

- 스킬에 "참고 자료는 <폴더 경로>" 를 적어두고, 앞으로 제안서를 쓸 때
  **먼저 그 폴더를 훑고 시작하라**고 규칙으로 넣어줘
- 같은 일을 하는 스킬이 이미 있으면 새로 만들지 말고 **덮어써 줘**
```

블로그도 똑같이 한 번 더 하면 됩니다 — 위에서 `제안서` 를 `블로그` 로만 바꾸세요.

**통과 기준** — 스킬 문서에 **내 실제 문장**이 근거로 인용돼 있으면 통과.
일반론("전문적이고 신뢰감 있게")만 적혀 있으면 자료를 안 읽은 것입니다. 다시 시키세요.

### 다 됐는지 확인

```
새로 고친 제안서 스킬로, 아무 고객사나 하나 잡아서 커리큘럼 표만 만들어줘.
내 기존 제안서와 모듈 개수·시간 배분이 비슷한지 스스로 비교해서 알려줘.
```

## 네 장을 다 했다면

| 전 | 후 |
|---|---|
| "다음 주 화요일 뭐 있지?" → 내가 캘린더를 연다 | 직원이 답한다 |
| "작년 그 제안서처럼 써줘" → 내가 파일을 찾아 붙여넣는다 | 직원이 폴더를 훑고 시작한다 |
| 매번 문체·구성을 다시 설명 | 스킬에 박혀 있다 |

> 🔒 **자료 창고는 읽기 전용입니다.** 직원이 원본을 고치지 못하게 팀 규약에 적어두세요.
> 산출물은 작업 폴더(`workspace/`)에 만들고, 원본 폴더에는 **아무것도 쓰지 않습니다.**
