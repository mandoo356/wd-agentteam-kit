# office — 가상 오피스 (모듈 5)

브라우저에 열리는 **픽셀 사무실**입니다. 내가 만든 직원들이 출근하고, 자리에 앉아 일하고,
회의실에 모입니다. 화면은 `workspace/` 폴더를 읽어서 그려집니다 —
**직원이 실제로 일을 해야 화면이 바뀝니다.** 장식이 아니라 현황판입니다.

---

## 켜는 법

```
npm install     ← 처음 한 번만. USB에서 복사했으면 건너뜁니다
npm run dev
```

브라우저에서 **http://localhost:3000**

> 여기는 `npm` 입니다. 슬랙 서버(`py`)와 헷갈리지 마세요.

| | 슬랙 서버 | 가상 오피스 |
|---|---|---|
| 폴더 | `slack-server/` | `office/` |
| 켜는 명령 | `py -3 -X utf8 server.py` | `npm run dev` |
| 보는 곳 | 슬랙 앱 | 브라우저 `localhost:3000` |

**둘 다 켜져 있어야** 회사가 온전히 돌아갑니다. 검은 창 두 개를 켜둔 채로 두세요.

---

## 화면 보는 법

| 무엇 | 어떻게 |
|---|---|
| 직원 출근시키기 | 화면 위 **"오늘 업무 시작하기"** 버튼. 안 누르면 아무도 안 움직입니다 |
| 직원 정보 보기 | 돌아다니는 직원을 **클릭** |
| 진행 현황 | 7단계 막대. 지금 각 일감이 어느 칸에 있는지 |

```
📥 문의 접수 → 💜 제안서 → 🤝 확정 → 🎓 설계 → 📚 제작 → 🎤 진행 → 🧾 정산
```

## 내 회사로 바꾸기

**`company.config.ts` 이 파일 하나만** 고칩니다. 저장하면 화면이 자동으로 바뀝니다.

| 고칠 것 | 어디 |
|---|---|
| 회사 이름, 로고 글자, 화면 제목 | `COMPANY` |
| 대표(나) 이름·성격 | `CEO_PROFILE` |
| 부서 12개 이름·아이콘 | `DEPARTMENTS` |
| 직원 이름·직책·색·혼잣말 | `STAFF_LIST` |
| 진행 중인 일감 | `COURSES` |

### 🚫 건드리면 안 되는 것 3가지

1. **부서 `id`** (`research`, `brand`, `finance` 같은 영어 단어) — 엔진이 이 id로 캐릭터를 움직입니다. 바꾸면 길을 잃어요. 바꿔도 되는 건 `name`·`icon`·`short` 입니다.
2. **부서 개수 12개** — 사무실이 4칸 × 3줄 고정입니다. 안 쓰는 부서는 지우지 말고 **이름만** 바꾸세요.
3. **`app/` 폴더** — 엔진입니다.

> 실수로 깨뜨렸으면 `git checkout office/` 로 되돌립니다.

### 💰 금액 규칙

**모르는 금액은 지어내지 말고 `0` 으로 두세요.** `note` 에 사유를 적습니다.
화면의 `0` 은 "무료"가 아니라 **"아직 확정 안 됨"** 이라는 뜻입니다.

## 연동(Notion·Discord)

화면에 **"미설정"** 이라고 뜨는 건 **오류가 아닙니다.**
연결 안 된 걸 연결됐다고 표시하지 않는 게 이 프로그램의 원칙이고, 그 상태로 완전히 정상 작동합니다.

진짜로 붙이고 싶으면 `.dev.vars.example` 을 복사해 `.dev.vars` 를 만듭니다.
🔒 **`.dev.vars` 는 비밀번호와 같습니다.** 남에게 폴더를 줄 때는 반드시 빼고 주세요.

---

## 안 될 때

| 증상 | 이렇게 |
|---|---|
| 화면이 안 열려요 | 검은 창이 닫혔는지 확인 → `npm run dev` 다시 |
| 직원이 안 움직여요 | 위쪽 **"오늘 업무 시작하기"** 를 눌러야 시작됩니다 |
| 3000번 포트가 쓰인대요 | 이미 켜져 있는 겁니다. 브라우저에서 `localhost:3000` 을 그냥 여세요 |
| 화면이 하얘요 | 쉼표(`,`)나 큰따옴표(`"`)를 빠뜨린 경우가 대부분입니다. `git checkout office/` 로 되돌리세요 |
| 부서를 지웠더니 깨졌어요 | 12개를 유지해야 합니다. 되돌리고 이름만 바꾸세요 |
